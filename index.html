Game dynamics

Each round both players show Heads or Tails. The matcher wins the stake if the coins match, the mismatcher wins it if they differ. Zero-sum: one player's gain is the other's loss.

Every pair of neighbours plays twice, once with each as the matcher, so everyone holds one strategy and can copy anyone.

Imitator settings

Copy probability is 1 / (1 + e−Δ/K), where Δ is the neighbour's total payoff minus your own. K = 0 means copy only if strictly better.

Learner settings

Learners sit at random sites chosen from the seed and are coloured by their strategy like everyone else (hover over a cell to see whether it is a learner). Changing the number during a run places a new set.

How the learners learn

Each learner sees only its own payoff, per partner per round, and never imitates. Each repeats three steps on its own:

  1. Measure. Play its kept vector for W generations and average its payoff.
  2. Try. Add a small random change to each of its five probabilities (normally distributed with standard deviation σ, clipped to 0–1) and play that for the next W generations.
  3. Keep or revert. If the trial window earned more than the window before it, the change becomes the kept vector and the next trial starts straight away. Otherwise it goes back to the kept vector and measures it again first, since the lattice has moved on.

A longer window judges each change over a longer stretch, long enough for neighbours to react to it (for example by copying it), at the cost of fewer trials. In sampled mode the payoffs a learner sees are the realised ones.

What happens in one generation
  1. Each player holds five probabilities of cooperating: p0 in the first round, then pCC, pCD, pDC, pDD after each outcome (own move first).
  2. Each player holds five probabilities of playing Heads: p0 in the first round, then pHW, pHL, pTW, pTL after playing Heads and winning, Heads and losing, Tails and winning, Tails and losing. Stated by win or loss, they mean the same in either role.
  3. Every pair of neighbours plays the set number of rounds. Each player's score for the generation is its average payoff per round in each of those games, added up over all its partners.
  4. Every pair of neighbours plays the set number of rounds twice, once with each player as the matcher. A player's score from a pair is its average payoff per round over the two games; its score for the generation adds these up over all its partners.
  5. Every player then picks one neighbour at random and compares the two scores. It copies that neighbour's whole vector with the Fermi probability, which grows with how much higher the neighbour scored. All players update at once.
  6. Scores have no memory. They come only from the games played in this generation and are thrown away afterwards, so a strategy that did well in earlier generations gets no credit for it. A copied vector starts the next generation with a fresh score.
  7. Learners, if there are any, skip the copying step. Each plays its own vector and changes it only by trial and keep (see Learner settings).
  8. Generation 0 is a lattice of uniformly random vectors drawn from the seed.

What closest to a named strategy means

A strategy here is compared on its four follow-up probabilities (pHW, pHL, pTW, pTL); the opening move only affects round one. The named strategies are:

  • always Heads (1, 1, 1, 1) and always Tails (0, 0, 0, 0)
  • win-stay lose-shift (1, 0, 0, 1): repeats its move after a win, switches after a loss
  • alternator (0, 0, 1, 1): switches every round, win or lose
  • 50/50 random (0.5, 0.5, 0.5, 0.5): the only strategy nobody can exploit

The distance between a player's four numbers and a named strategy's is the straight-line distance, √((pHW−q1)² + … + (pTL−q4)²), at most 2. A player counts as the closest named strategy if that distance is under 0.5, and as mixed otherwise.

What closest to a named strategy means

A strategy is five numbers (p0, pCC, pCD, pDC, pDD), so it is a point in a five-dimensional box. Each named strategy is a corner of that box:

  • ALLC (1, 1, 1, 1, 1): always cooperates
  • ALLD (0, 0, 0, 0, 0): always defects
  • TFT (1, 1, 0, 1, 0): opens with C, then copies the partner's last move
  • grim trigger (1, 1, 0, 0, 0): opens with C, defects forever once anyone defects
  • WSLS (1, 1, 0, 0, 1): repeats its move after a good outcome (CC, DC), switches after a bad one (CD, DD)

The distance between a player's vector p and a named vector q is the usual straight-line distance, √((p0−q0)² + … + (pDD−qDD)²). It is 0 for an exact match and at most √5 ≈ 2.24.

A player is counted as the closest named strategy if that distance is under 0.5, and as mixed otherwise. For example, (0.9, 1, 0.1, 0.2, 0) is 0.24 from grim trigger and 0.81 from TFT, so it counts as grim. TFT and grim trigger share one colour.

What payoff spread and exploitability show

Matching pennies is zero-sum, so the mean payoff is always exactly 0. What changes is who wins.

Payoff spread is the standard deviation of players' payoffs. It is 0 when every pairing is even, and grows when some players beat their neighbours at others' expense.

Exploitability is what the best possible opponent would earn per round against a player using the population's mean vector, in both roles and over the set number of rounds. It is computed exactly, round by round, and is 0 only for 50/50 random play. The learner's payoff, when it is switched on, is a live estimate of how exploitable its actual neighbours are.

Without mutation, imitation eventually leaves one vector, which earns 0 against itself, so the end state always looks calm in spread. Exploitability, or the learner, shows whether that survivor could be beaten.

What the reference lines show

Lattice is what players actually do with their neighbours.

Well-mixed takes the same players but pairs each with randomly chosen players from anywhere on the lattice, ignoring who sits next to whom. It is estimated each generation from 5,000 random pairs.

Mean vs mean is a single player using the population's average vector (the mean of each of the five probabilities) playing against itself, computed exactly.

The gaps separate two effects. Lattice above well-mixed is clustering: neighbours are more alike than random pairs, so cooperators meet cooperators more often. A gap between well-mixed and mean vs mean is diversity: payoff is not linear in the vector, so the average strategy is a poor stand-in for the actual mix, and it may describe nobody (half TFT and half ALLD averages to 0.5, 0.5, 0, 0.5, 0). Without mutation, imitation eventually leaves one vector, and then all three lines meet.

Both reference lines use the expected game outcome, also when the lattice uses sampled moves.
