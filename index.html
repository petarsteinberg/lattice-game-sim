Lattice

Game dynamics

Each round both players show Heads or Tails. The matcher wins the stake if the coins match, the mismatcher wins it if they differ. Zero-sum: one player's gain is the other's loss.

Every pair of neighbours plays twice, once with each as the matcher, so everyone holds one strategy and can copy anyone.

Continue: each pair's game carries on, so the next round answers the last one; p0 is used only in the very first round. Repeat: each generation starts a new game, opened with p0.

Not used in matching pennies: playing yourself in both roles always nets 0.

Expected averages over every way the rounds could go. Sampled plays the moves out with random draws.

What happens in one generation
  1. Each player holds five probabilities of cooperating: p0 for the first round, then pCC, pCD, pDC, pDD after each outcome (own move first).
  2. Each player holds five probabilities of playing Heads: p0 for the first round, then pHW, pHL, pTW, pTL after playing Heads or Tails and winning or losing.
  3. Every pair of neighbours plays the set number of rounds, picking up where it left off in a continued game. A player's score is its average payoff per round, added up over its partners.
  4. Every pair of neighbours plays the set number of rounds twice, once with each as the matcher. A player's score is its average payoff per round, added up over its partners.
  5. Each player picks one neighbour at random and copies its whole strategy if that neighbour scored more; otherwise it keeps its own. All players switch at the same time.
  6. Generation 0 is a lattice of uniformly random strategies drawn from the seed.

The lattice

Strategy mix

How strategies are categorized

A strategy here is compared on its four follow-up probabilities (pHW, pHL, pTW, pTL); the opening move only affects round one. The named strategies are:

  • always Heads (1, 1, 1, 1) and always Tails (0, 0, 0, 0)
  • win-stay lose-shift (1, 0, 0, 1): repeats its move after a win, switches after a loss
  • alternator (0, 0, 1, 1): switches every round, win or lose
  • 50/50 random (0.5, 0.5, 0.5, 0.5): the only strategy nobody can exploit

The distance between a player's four numbers and a named strategy's is the straight-line distance, √((pHW−q1)² + … + (pTL−q4)²), at most 2. A player counts as the closest named strategy if that distance is under 0.5, and as mixed otherwise.

How strategies are categorized

A strategy is five numbers (p0, pCC, pCD, pDC, pDD), so it is a point in a five-dimensional box.

  • ALLC (1, 1, 1, 1, 1): always cooperates
  • ALLD (0, 0, 0, 0, 0): always defects
  • TFT (1, 1, 0, 1, 0): opens with C, then copies the partner's last move
  • grim (1, 1, 0, 0, 0): opens with C, defects forever once anyone defects
  • WSLS (1, 1, 0, 0, 1): repeats its move after a good outcome (CC, DC), switches after a bad one (CD, DD)
  • banter (0.5, 0.5, 0, 1, 0.5): copies the partner after unequal moves, but leaves mutual cooperation or mutual defection half the time, so two banter players end up taking turns being exploited

The distance between a player's vector p and a named vector q is the usual straight-line distance, √((p0−q0)² + … + (pDD−qDD)²). It is 0 for an exact match and at most √5 ≈ 2.24. A player is counted as the closest named strategy if that distance is under 0.5, and as mixed otherwise.

In a continued game, p0 only opened the very first round, so a strategy is compared on its four responses (pCC, pCD, pDC, pDD): a point in a four-dimensional box.

  • ALLC (1, 1, 1, 1): always cooperates
  • ALLD (0, 0, 0, 0): always defects
  • TFT (1, 0, 1, 0): copies the partner's last move
  • grim (1, 0, 0, 0): cooperates only after mutual cooperation, so once anyone defects it defects for good
  • WSLS (1, 0, 0, 1): repeats its move after a good outcome (CC, DC), switches after a bad one (CD, DD)
  • banter (0.5, 0, 1, 0.5): copies the partner after unequal moves, but leaves mutual cooperation or mutual defection half the time, so two banter players end up taking turns being exploited (CD, DC, CD, ...)

The distance between a player's responses p and a named strategy's q is the usual straight-line distance, √((pCC−qCC)² + … + (pDD−qDD)²). It is 0 for an exact match and at most 2. A player is counted as the closest named strategy if that distance is under 0.5, and as mixed otherwise.
